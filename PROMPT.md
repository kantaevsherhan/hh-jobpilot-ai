# Промпт для старта работы над проектом

Скопируй это в новую сессию агента в папке проекта.

---

Ты работаешь над проектом **hh-jobpilot-ai** — локальное приложение для поиска вакансий на hh.kz и отправки откликов.

Прочитай два файла целиком, прежде чем что-то делать:

- `HH_AI_AGENT_MASTER_SPEC.md` — что именно нужно построить
- `CLAUDE.md` — как работать: тесты, коммиты, форматтеры, границы слоёв

Начни с **Фазы 1** (раздел §31 ТЗ) — каркас бэкенда и фронтенда плюс экран резюме.

Правила, которые нарушать нельзя:

1. Проекты создавай командами (`npm create vite@latest frontend -- --template vue-ts`, `alembic init`), а не руками файл за файлом.
2. Одна задача = один коммит. После каждой задачи: тесты → форматтер → линтер → коммит.
3. Тесты не должны требовать браузера, Ollama или интернета.
4. Всё уже настроено: `make setup` пройден, venv есть, модель qwen3:4b-instruct скачана. Запуск — `make dev`.

Сначала покажи разбивку Фазы 1 на задачи-коммиты и дождись подтверждения. Потом работай.

Если в ТЗ что-то непонятно или противоречиво — спроси, не додумывай.
