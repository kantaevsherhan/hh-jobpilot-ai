## Описание для YouTube

Показываю, как я настроил HH JobPilot AI для поиска работы на hh.kz. Вы добавляете своё резюме, выбираете профессии и регион, а приложение собирает вакансии, сравнивает их с вашим опытом и готовит черновики сопроводительных.

В видео пройдём весь путь от установки до первого поиска. Покажу, как настроить запросы для своей профессии, выбрать пример письма и отредактировать его перед откликом. Начнём с DRY_RUN, чтобы посмотреть результаты без отправки.

Приложение можно запустить бесплатно со своим аккаунтом hh.kz и локальной моделью Ollama. Поиск можно настроить под продажи, поддержку, бухгалтерию, IT или первую работу.

## План записи

1. На экране несколько вакансий и черновик письма. «Если каждое сопроводительное приходится писать с нуля, покажу, как я упростил этот процесс».
2. Открыть README и показать запуск на Windows или через Docker. Затем открыть «С чего начать».
3. На демонстрационном резюме настроить поиск по поддержке клиентов. Показать, где меняются запросы, зарплата, регион и формат.
4. Показать результаты пробного прогона, открыть карточку и поправить черновик. Коротко показать примеры для других профессий.
5. Закончить ссылками на проект и пост в Telegram.
